## 📁 檔案說明

### 1. 網頁版簡報 (index.html)
**使用方式**:
```bash
# 方法一：用瀏覽器直接打開
open index.html

# 方法二：啟動本地伺服器
python3 -m http.server 8000
# 然後瀏覽器開啟 http://localhost:8000
```

**特色**:
- ✅ 使用 Reveal.js 框架（業界標準）
- ✅ 支援鍵盤操作（→ 下一頁、← 上一頁、ESC 總覽）
- ✅ 自動適應螢幕大小
- ✅ 可匯出 PDF（按 E 鍵 → Print → 另存為 PDF）
- ✅ 支援全螢幕播放（F 鍵）
- ✅ 支援演講者模式（S 鍵）

**操作快捷鍵**:
- `→` / `Space` - 下一頁
- `←` - 上一頁
- `Home` - 第一頁
- `End` - 最後一頁
- `ESC` / `O` - 投影片總覽
- `F` - 全螢幕
- `S` - 演講者模式（顯示備註）

## 🎨 進階自訂

### 修改網頁版配色
編輯 `index.html` 中的 CSS 變數：
```css
.reveal h1 {
    background: linear-gradient(135deg, #00f5ff, #ff006e);  /* 修改這裡 */
}
.reveal .primary-color {
    color: #00f5ff;  /* 主色 */
}
.reveal .secondary-color {
    color: #ff006e;  /* 輔色 */
}
```

### 修改 PowerPoint 版配色
編輯 `generate_ppt.py` 中的顏色定義：
```python
PRIMARY_COLOR = RGBColor(0, 245, 255)      # 青色
SECONDARY_COLOR = RGBColor(255, 0, 110)    # 粉紅色
BG_COLOR = RGBColor(10, 14, 39)            # 深藍色
```

## 🆘 常見問題

### Q1: 網頁版無法顯示？
**A**: 確保所有檔案在同一資料夾，使用瀏覽器開啟（不要用記事本）

### Q2: PowerPoint 版字體跑掉？
**A**: 確保電腦有安裝「Microsoft JhengHei」字體（預設有）

### Q3: 如何匯出網頁版成 PDF？
**A**: 
1. 用 Chrome 瀏覽器開啟
2. 按 `E` 鍵進入列印模式
3. Ctrl/Cmd + P 列印
4. 選擇「另存為 PDF」

### Q4: 如何在投影機播放？
**A**: 
- 網頁版：按 `F` 鍵全螢幕播放
- PowerPoint：直接用簡報模式播放
